# Whist Calculator

Spielstand-App für Whist mit 4–6 Spielern. Läuft im Browser auf iPhone, iPad, Android und am Computer
und lässt sich auf den Home-Bildschirm legen.

**App öffnen:** https://oki58.github.io/Whist/

- Ansagen und Stiche per Button, Führungsfarben, Sprachansagen
- Gemeinsames Archiv und Statistik über Firebase (Firestore)
- Ansehen für alle mit dem Link, Speichern und Löschen nur mit PIN

Dateien: `index.html` (die App), `manifest.webmanifest` und `icons/` (Home-Bildschirm), `sw.js` (Offline-Cache),
`firestore.rules` (Zugriffsregeln, in der Firebase-Konsole unter Firestore → Regeln einfügen).
